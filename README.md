# `.gitkeep` files

Git won't commit an empty folder, so each one holds a `.gitkeep`.

The folders are part of the structure this project needs, this is why we are using this trick.

There are four (now at initial commit):

- `backend/src/main/kotlin/seg3502/carhms/application/dtos/queries/.gitkeep`
- `backend/src/main/kotlin/seg3502/carhms/application/usecases/.gitkeep`
- `backend/src/main/kotlin/seg3502/carhms/domain/.gitkeep`
- `backend/src/test/resources/seg3502/carhms/contracts/.gitkeep`

**Delete the `.gitkeep` once its folder has real files in it.**
